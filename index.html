RouteOptimizer

Aplicación web que optimiza rutas de visitas en Temuco. El usuario sube un archivo Excel con coordenadas, selecciona un área en el mapa y la app genera una ruta optimizada sobre calles reales, incluyendo cálculo de ruta desde la ubicación actual del usuario.

React Next.js TypeScript Leaflet.js OpenStreetMap Python · FastAPI AWS Amplify

ConnectMapNetwork

Visualización interactiva de infraestructura de fibra óptica en Chile. El mapa recorre el país de norte a sur y viceversa, mostrando flujo de tráfico y capacidad de ancho de banda por tramo (5–100 Gbps), con clasificación de hubs principales y nodos secundarios.

Sobre mí

Carlos Ariel Monroy Oñate, desarrollador full-stack en Temuco, Chile. Me enfoco en aplicaciones que combinan datos geoespaciales, mapas interactivos y buenas experiencias de usuario.

Trabajo principalmente con el ecosistema de React y Next.js en el frontend, Python y FastAPI cuando el proyecto necesita un backend de procesamiento, y despliego en AWS. Me interesan particularmente los problemas de ruteo, geolocalización y visualización de redes.
